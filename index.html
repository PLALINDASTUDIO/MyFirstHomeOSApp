Help & Guide

Understand every main section and how to use it step by step.

Quick tip: Use Search to find saved information, use your phone/tablet Back button to return through app pages, and use the moon/sun and gear controls for Theme and Settings.

Install & Open the App

Phone • Tablet • Computer

Phone

iPhone: open the hosted app link in Safari → Share → Add to Home Screen → Add. Android: open it in Chrome → menu (⋮) → Install app or Add to Home screen.

Tablet

iPad: Safari → Share → Add to Home Screen. Android tablet: Chrome → menu (⋮) → Install app / Add to Home screen.

Computer

Open the hosted My First Home OS App in Chrome or Edge, then use the install icon in the address bar or the browser menu → Install app. The standalone Full Version HTML can also be opened directly in a modern browser.

Tip: The hosted PWA should be opened online once so offline files can be cached. Use Backup & Restore before clearing browser data or moving to another device.

Dashboard

See the whole first-home picture at a glance.

How to use it
  • Check the four summary cards for Tasks, Home Calendar, Bills & Utilities and Maintenance Updates.
  • Click any summary card to jump straight to its section.
  • Use the hero shortcuts for a Home Update or Maintenance Log.

Home Profile

Keep the core details of your home and important spaces organized.

How to use it
  • Add a home or area name, type, key reference and general notes.
  • Use separate records for the main home, garage, yard or other important areas.
  • Keep each record practical and update details whenever something changes.

Home Log

Keep a simple record of what changed around the home.

How to use it
  • Choose the date, add who logged the update, then write the important home note.
  • Use this for move-in progress, maintenance checks, deliveries and household changes.
  • Review recent entries whenever you need a quick history of the home.

Home Calendar

Keep upcoming service visits, deliveries and home reminders together.

How to use it
  • Add the event title, date, time and provider or location.
  • The status updates automatically from Upcoming to Today and then Past based on the calendar date.
  • Use the notes area for questions or details you want to remember before the visit.

Bills & Utilities

Organize recurring home bills and utilities in one easy-to-find list.

How to use it
  • Enter the bill or utility name, billing cycle, amount or plan, and notes.
  • Use this section to keep recurring household costs easy to review.
  • Use it as an organizer and verify actual balances or due dates with each provider.

Tasks

Assign practical home responsibilities and see what is still open.

How to use it
  • Add a task, choose who is responsible, set a due date and priority.
  • Mark the task Done when it is completed, or reopen it if follow-up is needed.
  • Open tasks are counted automatically on the dashboard.

Maintenance Log

Keep a clear maintenance history from one job to the next.

How to use it
  • Write who handled the work and which home area or item it concerns.
  • Record what was completed and what still needs follow-up.
  • Review the latest maintenance notes so unfinished work is easy to spot.

Expenses

Track practical first-home spending in one place.

How to use it
  • Add the expense, amount, date and who paid it.
  • Use the history to see move-in, maintenance and household costs over time.
  • Keep entries descriptive so every cost is easy to understand later.

Contacts

Keep important people and service details easy to reach.

How to use it
  • Save the contact name, service or role, phone and email.
  • Use it for contractors, utilities, insurance, locksmiths and other important home contacts.
  • Update details when phone numbers or roles change.

Home Tools

Use three practical first-home tools: Move-In Checklist, Home Budget & Emergency Fund, and Maintenance Planner.

How to use it
  • Move-In Checklist helps you track utilities, security, supplies and first setup tasks.
  • Home Budget & Emergency Fund keeps monthly home costs and your repair-savings target together.
  • Maintenance Planner turns recurring home care into a simple schedule.
  • Each tool saves a reusable card you can edit as your home changes.

Documents

Track where important documents are stored.

How to use it
  • Add the document name, storage location, home/owner and a short note.
  • This version saves a reference to the document, not the actual file.
  • Use clear storage descriptions so you can find the document quickly later.

Settings

Manage app preferences and protect your locally saved data.

How to use it
  • Use Backup to download your saved data as a JSON file.
  • Use Restore when you want to load a previous backup.
  • Use the top-right theme button for Light/Dark Mode and the Settings icon for direct access.
